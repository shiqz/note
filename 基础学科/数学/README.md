# 数学

数学是自然科学的基础，也是计算机科学和人工智能的核心基石。本目录按照从基础到进阶的顺序组织数学知识。

- **[数学学习路线图：从0到高等数学](./数学学习路线图：从0到高等数学.md)** - 完整的数学知识体系与学习顺序指引，包含从启蒙到高等数学进阶的全阶段规划、各专业方向数学需求、推荐资源与学习误区

## 学习路径

建议按照以下顺序学习：

```text
算术基础 → 四则运算 → 数的分类与表示 → 基本代数/初等代数 → 线性关系 → 线性代数 → 微积分 → ...
```
