# 数学

数学是自然科学的基础，也是计算机科学和人工智能的核心基石。本目录按照从基础到进阶的顺序组织数学知识。

## 学习路径

建议按照以下顺序学习：

```text
算术基础 → 四则运算 → 数的分类与表示 → 基本代数/初等代数 → 线性关系 → 线性代数
```
